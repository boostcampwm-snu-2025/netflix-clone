# netflix-clone
넷플릭스 클론 프로젝트 - 5,6주차

## Search PRD
1. 상단 헤더에 존재하는 검색 아이콘을 누르면, 검색어를 입력할 수 있는 창이 뜬다.
| 검색어를 입력할 수 있는 창은 애니메이션 효과로 가로로 확대되며 펼쳐진다. 
2. 검색창에 focus를 가지면 최근 검색어 레이어가 노출된다.
| 최근 검색어는 최대 5개만 노출되며, 마우스로 선택하면 해당 검색어가 검색되고, 키보드 상하방향키로도 선택할 수 있다.
| "검색어"의 기준은 "엔터"를 치거나 검색 이후 클릭 액션이 발생한 검색어이다.
3. 검색 결과는 기존 페이지 위에 새로운 페이지에 구성된다. 1열에 4개의 카드로 구성되며, 카드에는 이미지와 제목 정보가 포함된다.
| 카드 호버 시 확대 액션이 있다.
4. 검색어 입력창의 X 버튼을 누르면 검색이 종료되며, 최근 검색어에서의 탐색 중에는 검색어 입력창을 제외한 다른 어떤 화면을 눌러도 검색이 종료된다. 검색 결과를 보고 있을 때에는 전체 헤더를 눌러도 검색이 종료된다.
